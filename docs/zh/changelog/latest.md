# 5.x 更新日志

## v5.4.0 (2026-10-05)

### ✨ 新增优化

- 新增支持 **RedisSearch** 查询引擎
  - 基础功能: 索引列表、新增索引、修改索引、删除索引
  - 查询功能：输入查询条件查询数据，可选分数是否显示
  - 浏览数据：点击键区切换为Search模式，并查询文档键
  - 索引信息: 原始信息查看，索引DDL还原查看，字段详情显示类型标签和权重
  - 其他扩展: 标签集合查看、同义词组可查看新增和编辑、样例插入、文档跳转等
- 键区: 新增Search模式，**按索引全文检索**
- 键区: 工具栏可配置 **显示内存占用**（默认关）
- 终端: **多行粘贴提示**确认作为单条命令或多条命令执行
- 官网: 新增 **实战手册**：慢日志专项治理、SSL 加密改造
- 其他细节
  - 键值：选中字段后 Auto 可识别小端 FLOAT32 向量（Vector32，仅查看）；Hash 等表格外部仍是 UTF-8
  - 键名框占位改为「Enter 扫描键名」，和全文检索分开
  - 键名框的精确勾选改到输入框左侧
  - 键列表的浮动删除图标移动到右键菜单
  - 终端右键复制选中文本后提示成功
  - 代码区域复制按钮默认改到右下角
  - 表格组件分页去掉跳转到第 N 页
  - 「刷新连接」改为「重载连接」；命令日志改用文档图标
  - 连接高级选项按钮改用提示，表单标签加宽
  - 平铺键列表为类型标签留出位置
  - 空页深色主题恢复 Logo 光晕
  - 升级前后端依赖（Vite+ 1.0.0、Tauri 2.12）
  - 后端代码全量重构优化，支持更多丰富功能添加

### 🐞 修复问题

- 修复平铺键列表的类型标签未显示问题
- 修复 List 区间扫到端点后仍多打一次空查询
- 修复 Stream 翻页刚好满一页时被当成结束

## [v5.3.0](https://mp.weixin.qq.com/s/P691_vhcJjZATq8qbRUtBw) (2026-09-25) 中秋节

### ✨ 新增优化

- 新增支持连接配置 **网络代理** （系统代理或手动配置）
- 新增支持 **TimeSeries 类型**（RedisTimeSeries的`TSDB-TYPE`）
  - 样本表：按时间戳与数值区间过滤，默认新→旧，可切换正序
  - 新增、编辑、删除样本；行可复制为 `TS.ADD`；可查看 `TS.INFO`
  - 键列表 Tag 为 **T**，支持按类型筛选
  - **折线图**使用当前已加载样本；底栏图标与命令菜单均可打开
- 其他细节
  - 键类型下拉：List / Array 改为 info 色并相邻排列
  - 命令监控、发布订阅时间列只显示时分秒；监控默认按新到旧排序
  - 慢日志耗时显示整数毫秒并右对齐

### 🐞 修复问题

- 删除表格中的元素后整表重扫，现只去掉当前行，扫描条件与排序保留 #168
- 修复切换键后表格页码仍停在旧页
- 修复 Redisson 编码探测时 Kryo 把 Marshalling 数据误读出来

## [v5.2.0](https://mp.weixin.qq.com/s/oMVi3OsBLD-yaMfBbpxesA) (2026-09-10)

### ✨ 新增优化

- 连接: **SSH 隧道** 完全重写，全模式支持（单机、集群、哨兵）
- TTL: 支持按时长或**过期时刻**设置，悬停显示本地与 UTC
- 值区: Hash 字段 TTL
  - 列显示过期时刻，悬停倒计时剩余
  - 记住 HTTL 开关，换键刷新不再重置
  - 字段过期可独立保存，只读编码也可改 TTL
- 信息页: 内存展示占系统内存百分比
- Redis 安装帮助: TLS 开关提前；哨兵/TLS 默认端口与产物目录调整
- 其他细节
  - 官网增加 Redis Docker 安装与 TLS 证书生成页
  - 字段编辑面板增加关闭按钮
  - STRING/JSON 保存钮增加 loading
  - 复制连接时保留原分组

### 🐞 修复问题

- 修复 Auto 对已加载大 value 有时误判（部分试解改为全量试解）
- 修复 SSL 勾选与服务端不符时卡住，**错配立刻精确提示**
- 修复哨兵 TLS 建连挂死，以及跳过证书校验时丢失客户端证书
- 修复新建连接时集群与哨兵可同时勾选
