# 5.x 更新日志

## v5.4.0 (2026-10-04)

### ✨ 新增优化

- 新增 **RedisSearch**（连接页「搜索」；需 Redis 8 Query Engine 或 RediSearch；极简模式不显示）
  - 索引列表：名称、前缀、文档数、记录数、词条数、字段数；可按名称和前缀本地筛选
  - **查询**：空条件按 `*`，问号里有语法提示；可看分数；点结果键打开键值页。按字段扫描条数取一页
  - 字段详情显示类型标签和权重；TAG 可查看标签集合。Hash 的向量字段按浮点数组展示
  - 同义词组可查看、新增和编辑（已有的词只能追加，去不掉）
  - 索引信息按对象展示；DDL 由 `FT.INFO` 还原成 `FT.CREATE`，弹框里可临时改，不写回服务器
  - **新建索引**：改完一条 `FT.CREATE` 再执行；集群打到每个 master。Hash / JSON 键详情可按当前已加载字段预填（先写成 TEXT）
  - 删除索引不带 `DD`，文档键保留。样例有电商发现、内容推荐，同名已存在则不覆盖
  - 更多菜单可切到键区浏览该索引。列表上有官网文档入口
  - 只读连接不提供新建、样例、删除和同义词写入
- 键区支持 **按索引全文检索**
  - 类型下拉增加 Search（没装模块时不出现）
  - 只取键名，不拉回向量字段；可加载更多、加载全部
  - 上次选中的索引按连接和库记住；问号与精确勾选改到输入框左侧
- 键列表可 **显示内存占用**（工具栏开关，默认关）
  - 可见行批量查 `MEMORY USAGE`，滚回来不再请求；大小取整（如 48B、4K）
  - 服务不支持该命令时隐藏开关并提示
- 终端：多行粘贴先确认作为单条命令，或按行逐条执行；右键复制选中文本后提示成功
- 官网新增 **实战手册**：慢日志专项治理、SSL 加密改造（中英）
- 其他细节
  - 键名框占位改为「Enter 扫描键名」，和全文检索分开
  - 表格分页去掉跳转到第 N 页
  - 「刷新连接」改为「重载连接」；命令日志改用文档图标
  - 连接高级选项按钮改用提示，表单标签加宽
  - 平铺键列表为类型标签留出位置
  - 空页深色主题恢复 Logo 光晕
  - 升级前后端依赖（Vite+ 1.0.0、Tauri 2.12）

### 🐞 修复问题

- 修复 VectorSet 表格、编辑、新增的列顺序不一致，统一为元素 → 向量 → 属性
- 修复 List 区间扫到端点后仍多打一次空查询
- 修复 Stream 翻页刚好满一页时被当成结束
- 修复旧数据里残缺的 SSH 配置缺端口
- 修复 `TSDB-TYPE`、`ReJSON-RL` 类型名映射

## [v5.3.0](https://mp.weixin.qq.com/s/P691_vhcJjZATq8qbRUtBw) (2026-09-25) 中秋节

### ✨ 新增优化

- 新增支持 **TimeSeries 类型**（RedisTimeSeries的`TSDB-TYPE`）

- 其他细节
  - 键类型下拉：List / Array 改为 info 色并相邻排列
  - 命令监控、发布订阅时间列只显示时分秒；监控默认按新到旧排序
  - 慢日志耗时显示整数毫秒并右对齐

### 🐞 修复问题

- 删除表格中的元素后整表重扫，现只去掉当前行，扫描条件与排序保留 #168
- 修复切换键后表格页码仍停在旧页
- 修复 Redisson 编码探测时 Kryo 把 Marshalling 数据误读出来

## [v5.2.0](https://mp.weixin.qq.com/s/oMVi3OsBLD-yaMfBbpxesA) (2026-09-10)

### ✨ 新增优化

- 连接: **SSH 隧道** 完全重写，全模式支持（单机、集群、哨兵）
- TTL: 支持按时长或**过期时刻**设置，悬停显示本地与 UTC
- 值区: Hash 字段 TTL
  - 列显示过期时刻，悬停倒计时剩余
  - 记住 HTTL 开关，换键刷新不再重置
  - 字段过期可独立保存，只读编码也可改 TTL
- 信息页: 内存展示占系统内存百分比
- Redis 安装帮助: TLS 开关提前；哨兵/TLS 默认端口与产物目录调整
- 其他细节
  - 官网增加 Redis Docker 安装与 TLS 证书生成页
  - 字段编辑面板增加关闭按钮
  - STRING/JSON 保存钮增加 loading
  - 复制连接时保留原分组

### 🐞 修复问题

- 修复 Auto 对已加载大 value 有时误判（部分试解改为全量试解）
- 修复 SSL 勾选与服务端不符时卡住，**错配立刻精确提示**
- 修复哨兵 TLS 建连挂死，以及跳过证书校验时丢失客户端证书
- 修复新建连接时集群与哨兵可同时勾选
