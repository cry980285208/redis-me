# 4.x 更新日志

### ✨ 新增优化

- 键值页编码
  - 新增 **JavaSerial** 查看
  - 新增 **Pickle** 查看（Python）

- 百万键全量扫描性能优化：COUNT/追加/节流建树 #141
- 其他细节
  - 刷新键加载中显示旋转 loading 图标
  - CodeMirror 快捷键移入扩展菜单，快捷键弹框补充标题

- 修复批量删除/导出按匹配预览或直接匹配时只扫一轮、键量大时漏键

- 修复 Mac 下编辑器/终端快捷键未对齐 `Cmd`（改用 Mod）
- 换键时提前校正视图模式，避免 JSON 闪一下

## [v4.4.0](https://mp.weixin.qq.com/s/O9uHI9wMX_cSoh3jBOkxzg) (2026-07-18)

### ✨ 新增优化

- 键值页: 扫描优化和键类型功能扩展
  - **字段扫描优化: Hash/Set/ZSet支持match参数，扫描进度和是否精确匹配**
  - **字段表格根据键类型设置合适的默认排序**
  - 扩展菜单新增命令帮助，根据键类型的不同进行默认分组过滤
  - 扩展菜单新增**对象自省**（OBJECT ENCODING / IDLETIME / REFCOUNT / FREQ）
  - Hash: 新增可选HTTL支持，**所有键**、所有值、复制键
  - List: 新增**索引范围查询**、升降序与 LPOP/RPOP，表格新增独立索引列和复制索引
  - Set: 新增SPOP支持
  - ZSet: 新增 **TopN 排名查询**、行菜单支持查看索引（ZRANK/ZREVRANK）、ZPOPMIN / ZPOPMAX、复制分数
  - Stream: 范围输入样式优化，支持升序/降序扫描，复制ID
- 键区
  - 优化键名称过长时的布局样式
  - DB 选择器宽度等样式微调
- 设置
  - 新增**安全阈值**与**预览字节**配置，界面布局优化
  - 字段默认扫描数改为 100
- 命令: 命令帮助的命令列一键跳转到官网
- 其他细节优化
  - 键 TTL 图标前增加分隔符
  - 刷新键、重置窗口提示优化
  - 隐藏社交菜单以减小打包体积

### 🐞 修复问题

- 修复 Safari 浏览器官网下拉菜单遮挡
- 修复部分场景 meCommands 的错误重复弹框问题

## [v4.3.0](https://mp.weixin.qq.com/s/k3KMigBxg3fJraezIMdP5Q) (2026-07-11)

### ✨ 新增优化

  - 恢复 **Binary 编码格式**（setbit 等场景需要）

  - 优化 Stream 值表格 ID 展示
  - String 键在 MEMORY USAGE 不可用时显示估算内存
  - 集群槽位与节点入口移至扩展菜单
  - 快捷键仅编辑器可见
- 官网
  - Windows 下载增加微软应用商店入口

- 细节
  - 只读模式隐藏新增键所在append
  - 导入连接时新分组文件夹默认折叠
  - 导出数据的预览键名高度调整，避免出现滚动条

## [v4.2.0](https://mp.weixin.qq.com/s/gREAYjVYH5V4KWpBNWFZVQ) (2026-07-04)

### ✨ 新增优化

- 命令解析: 对齐 redis-cli `sdssplitargs`，支持引号内转义与二进制参数
- 键值页
  - 新增「复制为命令」
  - 新增「创建副本」（单机 COPY / 集群 DUMP+RESTORE）
  - 键名旁新增定位按钮，点击后左侧键列表滚动至当前键
- 导入导出: 新增支持 CMD 命令格式
- 键区
  - 支持 F5 刷新键列表；沿用当前连接色，搜索图标同步更新
  - 刷新按钮和底部文字颜色使用当前连接颜色
  - 优化扫描进度预估，适配集群场景
- 连接
  - 连接编辑新增初始 db 输入框
  - 支持 Valkey 9+ 集群连接时指定初始 db
- 发布订阅: 消息内容支持选择编码，以便发送二进制消息
- 其他: 官网友情链接新增 Redisee

### 🐞 修复问题
