# 收藏目录功能 - 实现方案

> **实现状态**：✅ 已实现

> **关联**：收藏键见 `plans/07_favorite-keys.md`（已实现）；`docs/zh/changelog/future.md` 已登记「收藏文件夹功能」  
> **关键代码（预期）**：`src/utils/favorite.ts`（或旁路 `favorite-folder.ts`）、`KeyTree.vue` / 新目录树组件、`KeyMain.vue`

> 目标：右键收藏常用命名空间目录，在「我的收藏」中展开目录查看其下键，并与收藏键分区独立展示。

---

## 一、需求概述

### 1.1 核心需求

| 需求         | 说明                                          |
| ------------ | --------------------------------------------- |
| 右键收藏目录 | 正常键树中右键文件夹 →「收藏目录 / 取消收藏」 |
| 收藏标识     | 已收藏目录显示星标（与收藏键一致）            |
| 同一入口     | 仍走底栏「我的收藏」，不另开入口              |
| 目录下挂键   | 展开收藏目录时，在该目录节点下 SCAN 并展示键  |
| 与收藏键独立 | 上区目录、下区收藏键无数据联动                |
| 分区布局     | 上下可拖拽调高度；标题行可折叠成一行再点恢复  |

### 1.2 与收藏键的差异

|           | 收藏键                    | 收藏目录                                    |
| --------- | ------------------------- | ------------------------------------------- |
| 身份      | `RedisKey`（key + bytes） | 路径字符串，如 `user:profile`（无尾部 `:`） |
| 点击/展开 | 打开右侧值页              | 在该目录节点下加载 `path:*` 的键            |
| 存活语义  | 键可能已删                | 命名空间约定，即使当前无键也可收藏          |
| 列表位置  | 收藏模式**下区**          | 收藏模式**上区**                            |

### 1.3 设计原则

- **轻量**：不改后端，纯前端；存储与作用域对齐收藏键（`connId + db`）
- **复用**：SCAN / `buildScanPattern(..., loadFolder)` / 星标 / `el-splitter`（见 `AppMain.vue`）
- **独立**：目录区与收藏键区职责分离，互不改写对方数据源
- **简洁**：不混成一棵「假父子树」；目录扁平完整路径展示

### 1.4 明确不做

- 收藏父子目录隐含关系（只存精确 path）
- 底栏单独的「显示/隐藏目录|键」功能键
- 用全局底栏「加载更多/全部」续扫某个收藏目录
- 退出收藏模式再 `loadFolder` 的跳转方案（已否决）
- 跨 db 汇总、导入导出（后置）
- 与连接分组 `connGroups` 混用
- 双击分割条折叠；分隔符可配前的特殊兼容

## 二、数据模型

### 2.1 类型

```typescript
/** 收藏目录：路径与 KeyTree 文件夹 id 一致，无尾部 ':' */
export interface FavoriteFolder {
  connId: string
  db: number
  path: string
  favoritedAt: number
}
```

与 `FavoriteKey` 平行，不做成 discriminated union（降低对现有收藏键代码的扰动）。

### 2.2 存储

| 项     | 说明                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------ |
| API    | `useStorage`（`@vueuse/core`）                                                                   |
| Key    | `redis-me:favorite-folders`                                                                      |
| 作用域 | 全局数组，逻辑按 `connId + db` 过滤                                                              |
| CRUD   | `isFolderFavorited` / `addFavoriteFolder` / `removeFavoriteFolder` / `clearFavoriteFoldersForDb` |

清空当前库收藏：同一「清空收藏」入口，**键 + 目录一起清**。

### 2.3 布局持久化

| Key                       | 内容                                             |
| ------------------------- | ------------------------------------------------ |
| `redis-me:favorite-split` | 上下区高度比例；两侧折叠态（expanded/collapsed） |

## 三、收藏模式整体结构

```
┌─────────────────────────────────────┐
│ 搜索框（共用 1 个，见 4.6）             │
├─────────────────────────────────────┤
│ 📁 收藏目录 (N)                   ▾ │  ← 标题行：点击折叠/展开
│   ▾ user:session                    │
│       [HASH] user:session:a      ⭐ │  ← 挂在该目录下的 SCAN 结果
│       [STR]  user:session:b         │
│   ▸ order:2024:paid                 │  ← 未扫完时：右键目录「加载更多/全部」
├─────────── 拖拽分割条 ───────────────┤  ← el-splitter 纵向
│ 🔑 收藏键 (M)                     ▾ │  ← 标题行：点击折叠/展开
│   [ZSET] order:xxx               ⭐ │
│   [HASH] user:1001               ⭐ │
└─────────────────────────────────────┘
│ ← 退出收藏              更多…         │  ← 收藏模式底栏不再显示中间计数
└─────────────────────────────────────┘
```

### 3.1 两区关系

- **上区**：仅收藏目录及其展开后的子键
- **下区**：仅当前库收藏键（现有逻辑）
- **无联动**：点目录不会改下区数据源；下区也不影响上区
- **计数**：各区标题自行显示 `(N)` / `(M)`；收藏模式底栏中间计数去掉（多选模式下的选中计数仍保留）

### 3.2 目录展示形态

- **目录列表本身**：扁平完整路径一行一个，如 `user:session:temp`；**不**拼出未收藏的父节点树
- 排序：按 `path` 字典序（父子路径会自然相邻）
- **目录下的子键**：跟随设置 `keyShow`（树 / 列表），与正常键树一致
- 分隔符：与当前键树一致（硬编码 `:`；若未来可配分隔符再对齐）

### 3.3 空态

- 无收藏目录：上区标题 + 简短提示（如「右键文件夹可收藏目录」）
- 无收藏键：下区保持现有空态
- 仅一侧有数据：仍显示两区标题；用户可把空的一侧折成一行

## 四、交互详述

### 4.1 正常模式：收藏 / 取消收藏目录

- 入口：`KeyTree` 文件夹右键菜单（与「只加载该目录」等并列）
- 已收藏：目录节点显示星标；菜单为「取消收藏」
- 父子互不隐含：可同时收藏 `a` 与 `a:b`

### 4.2 展开目录 → 在节点下挂键

| 操作               | 行为                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------- |
| 首次展开未加载目录 | SCAN `path:*`（复用 loadFolder 语义），auto 加载至与主列表相同的阈值（`keyScanCount`）后停止 |
| 已加载再折叠/展开  | 使用缓存，不自动重扫                                                                         |
| 点击目录下的键     | 右侧打开值（与收藏键相同）                                                                   |
| 目录下键的星标     | 若该键也在收藏键列表中则亮星；可在此收藏/取消收藏键                                          |

### 4.3 目录级续载（加载更多 / 加载全部）

- 支持大目录；**按目录隔离状态**（每目录独立 `keyList` + `cursor` + `loading`）
- **不要**占用收藏模式底栏的全局「加载更多 / 加载全部」
- 未扫完时：在**收藏目录根右键菜单**提供「加载更多」「加载全部」（不做子树末尾行内入口）
- 与主列表 `scanKey` 拆开，避免抢全局 cursor / buffer
- 多目录同时展开：前端**无需额外排队**；连接侧 `conn` 已有 Mutex，并发 SCAN 在后端串行

### 4.4 再次扫描

- **右键收藏目录 →「重新加载」**：清空该目录子键与 cursor，重新 SCAN
- 不占用「再点目录」：单击/箭头仍是展开折叠
- 只影响当前目录子树，不动其它已展开目录与下区收藏键
- loading 建议按目录标记，避免整页不可点

右键菜单（收藏模式 · 目录）建议：

```
重新加载
加载更多      ← 仅未扫完时
加载全部      ← 仅未扫完时
复制路径
多选 / 退出多选
取消收藏
```

### 4.5 分区拖拽与折叠

| 能力       | 说明                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------- |
| 上下拖动   | 纵向 `el-splitter`，两区都展开时可调比例并持久化                                                  |
| 折叠       | 点击**分区标题行**（或右侧 ▾/▸），该区收成**底部/顶部一行**，仍显示 `收藏键 (M)` / `收藏目录 (N)` |
| 恢复       | 再点标题行，恢复折叠前高度                                                                        |
| 非完全隐藏 | 折叠后始终保留一行，不出现「完全消失」                                                            |
| 触发忌用   | 不用滚动条底部、不设底栏显隐专用键                                                                |
| 双侧折叠   | 允许都折成一行；折叠态用 flex 固定标题高度，不用 el-splitter（避免一侧被挤没）                    |

一侧折叠时：另一区占满剩余高度；分割条可隐藏或禁用拖拽。

### 4.6 过滤（共用 1 个搜索框）

收藏模式**顶栏只保留 1 个搜索框**（与现收藏键模式一致），不按区各做一套。

两区数据/点击仍独立；过滤只是**同一关键字分别应用到两区**（本地过滤，不触发 SCAN）：

| 区域          | 规则                                                                     |
| ------------- | ------------------------------------------------------------------------ |
| 上区 · 目录   | **path 匹配，或已加载子键中任一键名匹配** → 保留该目录；子键再按键名过滤 |
| 下区 · 收藏键 | 按键名过滤（现状）                                                       |

一侧折叠成一行时，顶栏搜索框仍在，规则不变。

### 4.7 退出收藏模式

- 底栏「退出收藏」：与现逻辑一致，回到正常扫描列表
- **丢弃**各目录的 SCAN 缓存（再次进入需重新展开加载）

## 五、状态机（收藏目录扫描）

每个 `path` 一份运行时状态（不入 localStorage）：

```typescript
interface FolderScanState {
  keys: RedisKey_Deserialize[]
  cursor: ScanCursor | null
  loading: boolean
  /** 是否已完成过至少一次加载（用于区分未加载 vs 空目录） */
  loaded: boolean
}
```

```
未加载 --展开--> loading --> 已加载(可未扫完)
                              ├─ 续载 --> 追加 keys / 更新 cursor
                              └─ 右键重新加载 --> 清空 --> loading --> 已加载
折叠：不改变 loaded/keys；仅 UI 收起
```

## 八、实现范围（一次做完，不分期）

1. 存储与 CRUD、正常树右键收藏/星标
2. 收藏模式上/下分区（两侧展开可拖；折叠用 flex）+ 标题行可折成一行（允许都折）
3. 展开目录 SCAN 挂键；子键展示跟随 `keyShow`；未扫完时右键加载更多/全部；右键重新加载
4. 共用搜索框（目录：path 或子键命中；下区：键名）
5. 清空收藏：键 + 目录一起清；确认文案覆盖两者
6. 分割比例与折叠态持久化
7. 退出收藏丢弃目录 SCAN 缓存；收藏模式底栏去掉中间计数

不做：双击分割条、分隔符可配兼容（等分隔符功能本身落地再跟）。

## 九、已定结论备忘

| 议题             | 结论                                                  |
| ---------------- | ----------------------------------------------------- |
| 与收藏键同树混排 | 否；上下分区                                          |
| 目录路径展示     | 扁平完整路径，不拼父树                                |
| 目录下子键       | 跟随 `keyShow`（树/列表）                             |
| 点击目录         | 在该目录节点下展示键，不退出收藏模式                  |
| 目录区 vs 键区   | 完全独立，无选中联动                                  |
| 续载             | per-directory 右键「加载更多/全部」；不进底栏、不行内 |
| 再扫             | 右键「重新加载」                                      |
| 分区显隐         | 标题行折叠成一行可恢复；允许两侧都折；无底栏显隐键    |
| 拖拽             | 两区展开时纵向 splitter 调高度并持久化                |
| 搜索框           | 共用 1 个；目录在 path 或子键命中时保留               |
| 清空             | 键 + 目录一起清                                       |
| 底栏计数         | 收藏模式去掉中间计数（标题自带数字；多选计数保留）    |
| 退出缓存         | 丢弃各目录 SCAN 缓存                                  |
| 分期             | 不分期，按第八节一次做完                              |
| 多目录同时 SCAN  | 前端不排队；后端连接 Mutex 串行                       |
