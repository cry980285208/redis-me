## 2. 字段编解码 / Auto / IPC Base64（#144）

### 2.1 回归必测（已修：FieldAdd wire）

- [ ] 打开普通 UTF-8 Hash（如 `user:1`，SCAN 后 bytes 为空）→「新增字段」→ 保存成功且写到**正确键**
- [ ] 同上对 List / Set / ZSet 各测一次新增字段
- [ ] 新建键（mode=key）：UTF-8 / Hex 键名 roundtrip 正确

### 2.2 展示与 Auto

- [ ] STRING：Auto 识别 JavaSerial / Pickle / MsgPack / StrJson；切编码**不**打 Redis
- [ ] STRING：解码失败显示统一错误文案 + 编辑器错误态，且不可保存
- [ ] Hash 字段弹窗：Auto 可识别 JavaSerial；只读不可保存；UTF8/Hex 可编辑保存
- [ ] 键级切 Hex 后表格展示变 Hex；再开字段弹窗仍可 Auto
- [ ] HKEYS / HVALS、ZSet TopN：展示为当前编码（非裸 base64）
- [ ] Pub/Sub：按 Hex / UTF8 发布消息内容正确
- [ ] Stream / JSON：数据编码下拉保持禁用（本版不改）

## 已知风险（不阻塞则可记，QA 时留意）

| 级别 | 项                         | 说明                                           |
| ---- | -------------------------- | ---------------------------------------------- |
| 中   | 每轮全量排序上屏           | 百万键时主线程可能越扫越卡；与「边扫边看」权衡 |
| 中   | 键树节点 id 用展示 `key`   | 两个非法 UTF-8 lossy 同文时可能碰撞            |
| 中   | 收藏目录 MATCH 未转义 glob | path 含 `*` `?` `[]` 时语义扩大                |
| 低   | Snap 仅认 `SNAP` 环境变量  | 误注入会关更新（概率低）                       |
| 低   | 收藏目录 SCAN 为 `path:*`  | 不含与 path 同名的精确键（命名空间设计）       |
