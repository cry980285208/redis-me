## 代码预复核结论（降低手测成本）

发版说明对照 `v5.3.1..HEAD` 的用户可见改动整理。下列项可按「已对过代码 / 已知限制 / 必手测」分配精力。

### 已对过代码（可轻测）

| 模块         | 结论                                                                                                |
| ------------ | --------------------------------------------------------------------------------------------------- |
| 搜索页入口   | `FT._LIST` 成功才出现「搜索」页；极简模式隐藏                                                       |
| 删除索引     | `FT.DROPINDEX` 不带 `DD`，文档键保留。界面不提供同时删键                                            |
| 新建索引     | 只接受一条 `FT.CREATE`；集群每个 master 各发一次，已存在则忽略                                      |
| 键区全文检索 | `NOCONTENT`，不带回字段和向量                                                                       |
| 搜索页向量   | Hash 的 VECTOR 按小端 FLOAT32 展示；JSON 数组保持文本                                               |
| 同义词       | `FT.SYNUPDATE` 只追加；界面提示已有的词去不掉                                                       |
| 键详情预填   | 仅 Hash / JSON、可写、非极简、已启用搜索；字段先写成 TEXT                                           |
| 内存开关     | `keyShowMemory` 默认关；不支持 `MEMORY USAGE` 时隐藏                                                |
| 只读终端     | `FT.SEARCH` / `FT.INFO` / `FT._LIST` 等为只读；`FT.CREATE` / `FT.DROPINDEX` / `FT.SYNUPDATE` 为写入 |

### 已知限制（不必当缺陷反复测，知悉即可）

| 级别 | 说明                                                           | 建议                            |
| ---- | -------------------------------------------------------------- | ------------------------------- |
| 设计 | 搜索页查询只取一页，条数用设置里的字段扫描，没有服务端翻页     | 键区全文检索才有加载更多 / 全部 |
| 设计 | 同义词已有词不能删除                                           | 划掉旧词只提示，不发删除        |
| 设计 | DDL、索引信息弹框可改文字，不提交到服务器                      | 真正创建走「新建索引」          |
| 设计 | 搜索页切库不自动重拉，要点列表上的查询按钮                     | 键区索引选择按「连接 + 库」记住 |
| 设计 | 样例同名索引已在当前库时不写键、不重建                         | 只提示已存在                    |
| 延后 | 聚合图表、查询库、向量向导、拼写检查、`FT.ALTER`、自动补全不做 | 勿当漏测                        |
| 体验 | 键列表内存为整数单位，0 字节不显示                             | 对照一个小字符串键              |

### 建议手测优先级（时间紧时按此顺序）

1. **样例 → 查询 → 点键**：电商发现或内容推荐灌上，搜一条，打开文档
2. **新建 / 删除**：键详情预填、手改 `FT.CREATE`、删除后文档还在
3. **键区 Search**：浏览数据、加载更多、换库后索引不错位
4. **Tag / 同义词**：看标签、追加同义词、只读连接无写入
5. **内存开关** 与 **终端多行粘贴**
6. **回归**：VectorSet 列顺序、List / Stream 翻页、v5.3.1 的 TimeSeries 与代理

## 1. 搜索页（v5.4.0 主功能）

灌数：连接页打开「搜索」→「样例」。需要可写连接。

### 1.1 列表

- [ ] 有模块：出现「搜索」页；没装模块：没有该页，其它页正常
- [ ] 极简模式：没有「搜索」页
- [ ] 样例「电商发现」创建 `idx:bikes_vss`；「内容推荐」创建 `idx:movies_vss`
- [ ] 同名样例再执行：提示已存在，不覆盖数据
- [ ] 列：名称、前缀、文档数、记录数、词条数、字段数；表头说明能看懂
- [ ] 点字段数打开字段详情：类型标签、权重正确；TAG 为深色可点
- [ ] 筛选框按名称、前缀本地过滤；右侧查询按钮重新拉取
- [ ] 导出列与界面列一致（含字段数）
- [ ] 列表上的官网链接能打开搜索文档
- [ ] 集群：多 master 下列表不重复；只读连接无「新建索引」「样例」

### 1.2 查询

- [ ] 点「查询」进入该索引，空条件按 `*` 立刻查出一页
- [ ] 问号提示含字段、短语、标签、数值、地理、与或非
- [ ] `@` 条件能命中（如电影年份或商品价格）；非法查询展示服务端原文
- [ ] 勾选「分数」出现分数列并重查；导出含分数列。取消后分数列消失
- [ ] 本页条数不超过设置里的字段扫描条数
- [ ] 点结果键切到键值页，能看到原来的 Hash 或 JSON
- [ ] 电影样例的向量列是浮点数组，不是乱码
- [ ] 返回列表后，再进查询条件被清空并重新按 `*` 搜索

### 1.3 信息、DDL、Tag、同义词

- [ ] 索引信息是对象展示（RESP2 连接不是扁平交替数组）
- [ ] DDL 能还原出 `FT.CREATE`，含前缀和字段类型；复制可粘贴
- [ ] 在 DDL / 信息弹框里改文字，关掉再开仍是原文，服务器索引不变
- [ ] Tag 集合、同义词：本地过滤没命中时表格还在，只是没有行；一组都没有、或没有 TAG 字段时也是空表，没有单独的空状态
- [ ] 同义词：新增一组（空格或逗号分词）；编辑只追加新词
- [ ] 编辑时划掉已有词：提示去不掉，列表里旧词还在
- [ ] 只读连接：可看 Tag 和同义词，无新增、无编辑

### 1.4 新建与删除

- [ ] 「新建索引」打开带语法高亮的 `FT.CREATE`；空文本不能执行
- [ ] 改索引名、前缀、字段类型后执行成功，列表能看到，查询能命中匹配前缀的键
- [ ] 粘贴非 `FT.CREATE`、或两条命令：拒绝，不发到服务器
- [ ] 重复创建：提示已存在
- [ ] 删除前是普通确认框，文案说明文档键会保留
- [ ] 确认后索引消失，文档键还在（`EXISTS` 或键树能看到）；取消则不动
- [ ] 集群：新建后各分片都能查到；不要漏掉某个 master
- [ ] Hash 键详情「新建索引」：前缀取到最后一个冒号，已加载字段写成 TEXT，并切到搜索页
- [ ] JSON 键详情：字段写成 `$.字段`。STRING / List 等没有该菜单
- [ ] 只读、极简、未装模块：键详情没有「新建索引」

## 2. 键区全文检索

- [ ] 类型下拉第一项为 Search（放大镜）；没装模块时没有这项
- [ ] 选中后输入框占位为「Enter 全文检索」，下方出现索引下拉
- [ ] 空条件按 `*` 列出键名；问号与精确勾选在输入框左侧
- [ ] 普通扫描时占位仍是「Enter 扫描键名」
- [ ] 带 `@字段` 的条件只列出命中键；结果里没有向量二进制
- [ ] 加载更多、加载全部、暂停能翻完；条数与搜索页同一条查询的总命中一致
- [ ] 换索引会清空条件并重查；刷新索引名时，选中项没变则保留当前列表
- [ ] 搜索页「浏览数据」切到键区，选中该索引并查出键
- [ ] 换库后再进 Search：用的是当前库的索引，不沿用上一库的名字
- [ ] 搜索页已打开时切库：列表不会自己变，点查询按钮后变为当前库
- [ ] 树形 / 平铺都能展示命中键；点键打开正常

## 3. 键列表内存

- [ ] 默认不显示内存；工具栏可打开「显示内存」
- [ ] 打开后叶子行右侧出现整数大小；滚出再滚回不闪一下重新请求
- [ ] 关掉后星标位置正常，平铺列表类型标签不被挤掉
- [ ] 重命名、删除、刷新键列表后，大小按新键重查
- [ ] 不支持 `MEMORY USAGE` 的实例：开关不可用，并有提示
- [ ] 目录上的「目录内存分析」仍可用，与行上的大小互不干扰

## 4. 终端

- [ ] 粘贴两行以上：弹出确认，可选「单条命令」或「多条命令」
- [ ] 单条：换行被收成一条执行；多条：每行各执行一次
- [ ] 取消对话框：不执行
- [ ] 只粘贴一行：不弹窗，行为与以前一样
- [ ] 右键有选区：复制成功有提示；没有选区则粘贴
- [ ] 只读终端可以执行 `FT.INFO` / `FT.SEARCH` / `FT._LIST`，拒绝 `FT.CREATE` / `FT.DROPINDEX`
