## 代码预复核结论（降低手测成本）

发版前已做过一轮静态/路径复核。**无 P0 阻断**；下列项可按「已复核 / 已知限制 / 必手测」分配精力。

### 已复核通过（可轻测或跳过深挖）

| 模块                   | 结论                                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| VectorSet 后端扫描     | `field_scan_vectorset_page` 双 Pipeline 拆分（VEMB / VGETATTR），同 key 同 slot `req_packed_commands` 整批路由 |
| 单元素失败容错         | VEMB / VGETATTR 失败用占位值（向量 `-` / 空串），不拖死整页                                                    |
| 显式双模式             | `FieldScanMeta.vectorset_sample` 分支 VRANDMEMBER / VRANGE；错误直接透出，无隐式降级                           |
| VSIM WITHATTRIBS 兼容  | 方案 b：带参失败则去参重试，VGETATTR pipeline（1 RTT）补属性，前端无感                                         |
| PIPELINE 日志          | `parse_pipeline_first` + redis-cli 风格转义；单元测试覆盖 offset 跳过 / 截断 / 二进制转义                      |
| 元素编辑保存刷新       | 保存后单行刷新走 `field_get0` 兜底路径（VISMEMBER + VEMB + VGETATTR）                                          |
| FieldScanMeta 拼写修正 | 定义 + 引用 + tauri-specta 类型绑定已同步重生成                                                                |
| 静态检查               | `vp check` / `vp test` 通过                                                                                    |

### 已知限制（不必当缺陷反复测，知悉即可）

| 级别 | 说明                                                                | 建议                          |
| ---- | ------------------------------------------------------------------- | ----------------------------- |
| 延后 | VLINKS / VEMB RAW / FP32 输入 / REDUCE 降维 / 量化选项 UI 本版不做  | 勿当漏测                      |
| P2   | VSIM FILTER 自动补全、样例数据集一键导入、FieldAdd 多行批量未做     | 勿当漏测                      |
| 设计 | 随机采样（VRANDMEMBER）无分页，仅范围查询支持游标续页               | 语义使然，非缺陷              |
| 体验 | Q8 量化键 VEMB 返回近似值，界面带有近似提示                         | 对照 `quant-noq` 验证提示可见 |
| 兼容 | 字段扫描默认值 100 → 20 仅影响默认/重置后的值，已保存的用户设置不变 | 重置设置后验证即可            |
