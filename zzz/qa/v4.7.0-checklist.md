### 建议手测优先级（时间紧时按此顺序）

3. **配置页**：Redis 8.10 Diff；对比 8.2 不误选 8.10
4. **只读 + 重构冒烟**：只读无插入；Info/Value/ACL/配置/编解码弹窗能开
5. **v4.6.1 回归**：收藏目录边扫边上屏、Linux 缩放（有环境再测）

## 1. Array（v4.7.0 主功能，Redis ≥ 8.8）

灌数：

```bash
python test/serialization/ArraySeed.py
# 或: python test/serialization/ArraySeed.py 127.0.0.1 6379 <password>
```

### 1.1 基础读写（18.1）

- [ ] 新建 Array 键成功；键树 Tag 为 **A**（warning 色）
- [ ] 扫描类型「ALL」简称 Tag 为 **-**（下拉与按钮一致）；其它类型简称不变
- [ ] `tiny` / `page-dense`：表格仅已填充槽；列 index / value
- [ ] Header 同时展示 **ARCOUNT**（元素数）与 **ARLEN**（逻辑长度）
- [ ] `sparse-basic`：删槽留空洞后重扫，空洞不出现；ARCOUNT ≠ ARLEN 时展示正确
- [ ] 指定索引写入（ARSET）/ 改值 / 删行正常
- [ ] 游标插入（ARINSERT）正常（非末尾追加；从插入光标起连续写入）
- [ ] 精确勾选 + 索引：有值命中；空槽空表；非法索引提示可理解
- [ ] 复制为命令：整键（ARMSET）/ 单行（ARSET）可粘贴执行（可用 `armset-shuffle`）
- [ ] 字段编解码 Auto 与 Hash 一致
- [ ] Redis &lt; 8.8：新建/读写 Array 失败，错误可理解（无静默空页）

### 1.2 浏览增强（18.2）

- [ ] `range-clusters`：索引范围 0–4 / 50–54 / 200–204；分页续扫正确
- [ ] 大稀疏数组浏览不卡死（勿整段 ARGETRANGE）
- [ ] LastN（`lastn` / `lastn-many`）：插入序 / 最近优先；过滤值；nil 展示为 `(nil)`
- [ ] FieldAdd：指定索引 vs 游标插入两种模式

### 1.3 ARINFO（18.3）

- [ ] 值区「更多」→ Array 信息：展示 count / len 等元数据
- [ ] **不在**键头统一「更多」菜单中出现
- [ ] 只读连接：ARINFO / LastN 可读；无「插入」、无法删改

### 1.4 边界

- [ ] `high-index`（约 9e15）：表格展示、精确查、删改是否一致
- [ ] `binary` / `unicode` / `big-value`：编码与大值展示可接受
- [ ] `mixed-write`：ARSET + ARINSERT 后 ARSCAN / LastN
- [ ] 集群连接：读写 + LastN + ARINFO 各走一遍
- [ ] 回归：List / Hash / Set / ZSet / Stream 读写扫描与 4.6.0 一致
